# Neon Bastion

Neon-Incremental-Tower-Defense im Browser. Läuft auf Desktop, iOS und Android.

**Spielen:** https://neonbastion.de

- Quellcode: `src/` · Build: `python3 build.py` → `docs/` (wird von GitHub Pages ausgeliefert)
- Tests: `python3 tests/run_all.py`
- Balancing-Simulation: `node sim/sim.js --hilfe`
- Projektwissen für Entwickler und Claude Code: `CLAUDE.md`
